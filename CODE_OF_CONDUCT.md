# Code of Conduct

## The short version

Be decent to each other. This project is about having fun with terminal roasts, not roasting actual people in the community.


## What is expected

Treat everyone who contributes or asks questions with basic respect regardless of experience level, language, background, or where they are from.

Criticism of code or ideas is fine. Personal attacks, harassment, and discrimination are not.

If you see someone struggling with something, help them out or point them to the right place. Not everyone contributing roasts is a developer.


## What is not okay

Insulting or harassing contributors, maintainers, or users in issues, pull requests, or any other project space.

Discriminatory language or jokes targeting any group of people. The roasts in this project target bad code and typos, not people.

Dismissing contributions because someone is new or not a developer. Adding a roast in your language is a valid contribution even if you have never touched bash before.


## If something goes wrong

If someone is behaving badly in this project, email nishanthc264@gmail.com. Describe what happened and include links if possible. Reports are handled privately.


## Enforcement

Behaviour that violates this code of conduct may result in comments being removed, contributions being rejected, or the person being blocked from the project depending on the severity.
